# Deka Sport Passion – sito demo

Proposta di sito web realizzata da Salvo (Instagram @_s_alvo) per Deka Sport Passion, Sant'Agata sul Santerno (RA).

**Non è il sito ufficiale del negozio.** È una demo da presentare ai titolari: le parti tra parentesi quadre (es. [PREZZO]) sono da completare con dati reali, e il modulo di prenotazione non invia richieste.

Pagine: Home, Officina e biomeccanica (con prenotazione), Eventi, Shop, Contatti.
